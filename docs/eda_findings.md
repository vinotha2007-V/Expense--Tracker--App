# EDA Findings

This report reflects the actual values calculated from the cleaned synthetic transaction dataset in `data/processed/expenses_clean.csv`.

- Total income: ₹13,249,823.68
- Total expenses: ₹2,129,464.14
- Net savings: ₹11,120,359.54
- Average expense transaction: ₹3,072.82
- Median expense transaction: ₹2,560.13

## Expense breakdown by category
The highest expense category in the dataset is `Shopping`, followed by `Transport`, `Entertainment`, `Utilities`, `Rent`, `Healthcare`, `Education`, `Other`, and `Food`.

## Notes
- The dataset includes both income and expense records, and all income rows are categorized as `Salary`.
- No rows were dropped during the final cleaning validation in this phase.
- The calculations are based on synthetic data only and are not intended to reflect real financial behavior.
